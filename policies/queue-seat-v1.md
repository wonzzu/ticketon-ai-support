# TicketOn 대기열·좌석 정책

이 문서는 TicketOn의 예매 대기열, 좌석 선택과 임시 선점 기준을 안내합니다.

## QUEUE-01 대기열 진입

공연 회차의 예매에 참여하려면 해당 회차의 대기열을 통과해야 합니다. 입장 차례가 되기 전에는 좌석 선택과 예매 요청을 진행할 수 없습니다.

대기열은 공연 회차별로 운영되므로 서로 다른 회차의 대기 순번과 입장 권한은 공유되지 않습니다.

## QUEUE-02 대기 순서 결정

대기 순서는 TicketOn 서버에 대기열 등록이 완료된 순서로 결정됩니다. 사용자가 예매 버튼을 누른 시각이나 요청이 네트워크에서 출발한 시각만으로 순서를 보장하지 않습니다.

같은 시각에 여러 요청이 도착하더라도 각 회원에게 서로 다른 순번이 부여되며, 먼저 등록된 회원부터 입장합니다.

## QUEUE-03 대기 상태 갱신과 자동 입장

대기 화면에서는 내 앞의 대기 인원과 상태를 3초마다 갱신합니다. 일시적으로 조회에 실패하면 다음 갱신 시점에 다시 확인합니다.

입장 차례가 되면 별도의 버튼을 다시 누르지 않아도 좌석 선택 화면으로 자동 이동합니다.

## QUEUE-04 예매 화면 입장 권한 유지 시간

대기열을 통과해 얻은 예매 화면 입장 권한은 최대 10분간 유지됩니다. 10분 안에 예매 요청을 시작하지 않으면 입장 권한이 만료될 수 있습니다.

입장 권한이 만료된 뒤 예매를 진행하려면 해당 공연 회차의 대기열에 다시 진입해야 합니다. 입장 권한 10분은 좌석 임시 선점 7분과 서로 다른 시간입니다.

## QUEUE-05 새로고침과 중복 대기열 진입

같은 회원이 같은 공연 회차의 대기 화면을 새로고침하거나 다시 진입해도 새로운 순번을 중복으로 발급하지 않습니다. 기존에 대기 중이라면 기존 순번을 유지하고, 이미 입장한 상태라면 남아 있는 입장 권한을 확인합니다.

입장 권한이 이미 만료된 뒤 다시 진입하면 새로운 대기 순번이 부여될 수 있습니다.

## SEAT-01 화면 선택과 좌석 선점의 차이

좌석 선택 화면에서 좌석을 클릭한 것만으로는 해당 좌석이 임시 선점되지 않습니다. 선택한 좌석으로 예매 요청이 성공해야 좌석 임시 선점이 시작됩니다.

좌석을 선택한 뒤 예매 요청을 완료하기 전에 다른 회원이 먼저 선점하면 해당 좌석을 사용할 수 없으며, 최신 좌석 상태를 확인해 다시 선택해야 합니다.

## SEAT-02 좌석 임시 선점 시간

예매 요청이 성공하면 선택한 좌석은 해당 회원에게 7분간 임시로 보호됩니다. 7분은 좌석을 화면에서 클릭한 시점이 아니라 예매 요청이 성공한 시점부터 계산합니다.

임시 선점 시간 안에 결제를 완료해야 예매가 확정됩니다. 화면에 표시된 남은 시간과 관계없이 최종 만료 여부는 결제 요청 시점의 좌석 선점 상태를 기준으로 판단합니다.

## SEAT-03 동일 좌석에 대한 동시 요청

여러 회원이 동일한 좌석을 동시에 예매하려고 하면 가장 먼저 임시 선점에 성공한 한 명만 해당 좌석을 사용할 수 있습니다.

먼저 화면에서 좌석을 클릭했더라도 예매 요청이 늦게 처리되면 선점에 실패할 수 있습니다. 선점에 실패한 회원은 다른 좌석을 선택해야 합니다.

## SEAT-04 좌석 선점 만료와 자동 해제

임시 선점 후 7분 안에 결제가 완료되지 않으면 해당 좌석은 자동으로 해제됩니다. 해제된 좌석은 다른 회원이 선택할 수 있습니다.

선점이 만료된 예매 건으로는 결제를 계속 진행할 수 없습니다. 좌석을 다시 확보하려면 최신 좌석 상태를 확인하고 예매를 처음부터 다시 진행해야 합니다.
